# Images Folder

## How to Add Your Photos

Replace the placeholder content in this folder with your actual anniversary photos.

### Recommended Organization:

1. **Wedding Photos**: `wedding_1.jpg`, `wedding_2.jpg`, etc.
2. **Family Photos**: `family_1.jpg`, `family_2.jpg`, etc.
3. **Vacation Photos**: `vacation_1.jpg`, `vacation_2.jpg`, etc.
4. **Celebration Photos**: `celebration_1.jpg`, `celebration_2.jpg`, etc.
5. **Everyday Moments**: `everyday_1.jpg`, `everyday_2.jpg`, etc.
6. **Special Moments**: `special_1.jpg`, `special_2.jpg`, etc.
7. **20 Years Photos**: `twenty_years_1.jpg`, `twenty_years_2.jpg`, etc.

### Image Guidelines:

- **Format**: JPG, PNG supported
- **Resolution**: 1920x1080 or higher recommended for best quality
- **Orientation**: Both portrait and landscape supported
- **File size**: Keep under 5MB per image for smooth app performance

### Important Files:

- Add your best anniversary photo for the celebration screen
- Add background images if you want custom backgrounds

## Tips:

- Use high-quality images for the best visual experience
- Crop and edit photos before adding them to maintain consistency
- Keep file names organized and sequential for easy management
